# Использование raw-radio-studio

> Это русский перевод [`docs/USAGE.md`](USAGE.md). При расхождениях
> авторитетным считается английский оригинал.

Краткое, ориентированное на задачи руководство по функциям, которые есть
сегодня. Оно использует **фактические имена UI**, показанные в приложении
(подписи кнопок, заголовки панелей, всплывающие подсказки).

Все действия ниже выполняются в главном окне, если не указана панель. Сессии —
это проекты Tracktion Engine, сохраняемые как файлы `.tracktionedit`; место по
умолчанию — папка `Projects/` приложения (см.
[Где что лежит](#где-что-лежит)).

> **Статус: pre-alpha.** Меню и подписи могут меняться. Это руководство
> соответствует текущей сборке.

---

## 1. Открыть, сохранить и восстановить проект

Кнопки сессии — первая группа в строке действий (только иконки, наведите курсор,
чтобы увидеть подсказку):

| Кнопка | Иконка | Действие |
| --- | --- | --- |
| **New** (Создать) | `file-plus` | Новая сессия (запрос Save/Discard/Cancel, если в текущей есть несохранённые изменения). |
| **Open** (Открыть) | `folder-open` | Открыть сессию `.tracktionedit`. |
| **Save** (Сохранить) | `floppy-disk` | Сохранить на месте. |
| **Save As** (Сохранить как) | `floppy-disk-back` | Сохранить в новый файл `.tracktionedit`. |
| **Close** (Закрыть) | `x` | Закрыть сессию (тот же запрос о несохранённых изменениях). |

Сессии периодически автосохраняются (интервал в **Settings**); если предыдущий
запуск был прерван, диалог **Session recovery** предлагает **Restore** или
**Discard**. Записанные дубли лежат в папке `Recordings/` рядом с файлом сессии.

## 2. Плагины

VST3 доступен всегда; **LV2** включается опционально при сборке; **AU** только на
macOS. VST2 никогда не поставляется.

1. Нажмите **Plugins** в строке действий (иконка `waveform`), чтобы открыть
   панель **Plugins**.
2. В панели выберите целевой трек в списке треков сверху, затем нажмите **Scan**
   для сканирования папок плагинов (сканирование выполняется вне процесса, так
   что падающий плагин не может уронить приложение). Используйте **Refresh**,
   чтобы перечитать список из известных плагинов.
3. Введите текст в поле поиска (**Search plugins (name, maker, format)**), чтобы
   отфильтровать список **Available plugins**. Выберите строку плагина.
4. Нажмите **Insert** (или дважды кликните по строке), чтобы вставить его на
   выбранный трек. Плагин становится частью Edit и сохраняется вместе с проектом.
5. Выберите плагин в выпадающем списке **Track plugin** и нажмите **Open**, чтобы
   показать окно его редактора. **Remove** удаляет его с трека.
6. **Save** / **Save As** проект, чтобы сохранить вставленный плагин и его
   состояние.

Всплывающие подсказки на каждой кнопке описывают действие; строка состояния внизу
списка показывает прогресс сканирования и число известных плагинов.

## 3. Пресеты (пользовательские пресеты для размещённого плагина)

Секция **Presets** находится в нижней половине панели **Plugins**:

- **Preset** + выпадающий список + **Load preset** — выберите сохранённый пресет
  и загрузите его в плагин выбранного трека.
- **New** + поле имени + **Save preset** — введите имя и сохраните текущее
  состояние плагина.

Шаги сохранения: откройте панель **Plugins**, вставьте/выберите плагин трека,
введите имя в поле **New**, нажмите **Save preset**. Имя должно быть непустым и
не должно содержать разделителей пути.

Шаги загрузки: выберите имя в выпадающем списке **Preset**, нажмите **Load
preset**.

**Где лежат файлы.** Каждый размещённый плагин получает свою папку, и каждый
пресет — один файл:

```
<app data>/raw-radio-studio/Presets/<plugin-key>/<preset-name>.rrspreset
```

На macOS `<app data>` — это `~/Library/Application Support`; на Linux —
`~/.config`. `<plugin-key>` — безопасный для файловой системы ключ, производный
от имени/формата/идентификатора плагина. Пресеты — это сырое состояние плагина,
поэтому они осмысленны только для того же самого плагина.

## 4. Маршрутизация

Нажмите **Routing** в строке действий (иконка `headphones`), чтобы открыть панель
**Routing & Cue Mixes**. Выберите трек в выпадающем списке треков сверху; его
элементы управления обновятся соответственно.

### Назначение выхода трека на устройство

Используйте выпадающий список выходов в строке трека (подсказка **Hardware output
pair this track plays to**). Он перечисляет **Default output** плюс каждую
доступную аппаратную пару выходов. Выбор устройства направляет этот трек на него;
**Default output** возвращает его на основной выход. Переключатель/слайдер
**Send** в этой строке — это посыл выбранного трека в выбранный кью (см. §5).

### Submix / папка-трек (шина или группа)

Секция **Submix folder**:

1. Нажмите **New bus**, чтобы создать папку субмикса (имя задаёт приложение).
2. Выберите трек и шину, затем нажмите **Assign**, чтобы переместить трек в
   субмикс. Теперь его звук идёт через шину на мастер.
3. Нажмите **Unassign**, чтобы вернуть трек на верхний уровень.

### Aux send / return

Aux send/return реализован как **software cue mix** (см. §5): **Add cue**
создаёт шину aux-return, и **Send** каждого трека питает её. Трек возврата
появляется в списке треков маршрутизации с пометкой **`(cue)`** и имеет
собственный выпадающий список выходов, чтобы его можно было направить на
отдельную аппаратную пару.

## 5. Кью-миксы

Кью-микс — это отдельный мониторный микс для исполнителя (FR-MON-3/4), построенный
как aux send/return.

1. Нажмите **Routing**.
2. В секции кью нажмите **Add cue**, чтобы создать кью. Это добавляет трек
   aux-return, который питается посылами отдельных треков и, когда существует
   свободная пара выходов, направляет возврат на следующий свободный аппаратный
   выход (иначе он откатывается на основной выход — строка состояния сообщает
   счётчики).
3. Выберите трек, включите переключатель **Send** и задайте слайдер **Send** (дБ).
   Этот трек теперь слышен в кью.
4. Используйте выпадающий список выходов кью (подсказка **Hardware output pair
   the cue is sent to**), чтобы отправить кью на конкретную аппаратную пару.
5. **Remove cue** удаляет кью и его возврат.

> **Текущее ограничение.** UI задаёт **один посыл за раз** (выбранный трек в
> выбранный кью). Чтобы дать исполнителю действительно отдельный физический микс,
> нужен аудиоинтерфейс с **несколькими парами выходов**; на одном стерео-выходе
> кью откатывается на основной выход и не может быть отделён. Задавайте уровни
> посыла для каждого трека по очереди.

## 6. Экспорт стемов

**Export stems** находится в строке действий (текстовая подпись рядом с иконкой
`download-simple`; подсказка **Export stems: one 24-bit WAV per track plus the
master mix…**).

1. Нажмите **Export stems**.
2. Выберите папку назначения в диалоге выбора файлов.
3. Приложение отрендерит в эту папку:
   - один **`<Track name>.wav`** на каждый трек, у которого есть клипы
     (собственный выход трека, до мастера), и
   - один **`<Session name> master.wav`** (полный микс через мастер-цепочку).

Все файлы — **24-битные** с частотой дискретизации сессии (частота открытого
устройства или значение по умолчанию 48 кГц, когда устройство не открыто).
Рендеринг выполняется офлайн/быстрее реального времени; по завершении приложение
возвращается к обычному воспроизведению и мониторингу.

## 7. Экспорт региона

1. **Shift-drag on the timeline ruler** (Shift-перетаскивание по линейке времени)
   в верхней части аранжировки, чтобы выделить регион. Показание под линейкой
   отображает начало/конец и длину, а регион затеняется по всем дорожкам.
2. Нажмите **Export region** в строке действий (иконка `download-simple`;
   подсказка **Export the selected region to 24-bit WAV (Shift-drag on the ruler
   to select)**).
3. Выберите файл назначения. Экспортированный WAV содержит ровно выделенный
   интервал, 24-битный с частотой сессии.
4. Нажмите **Clear region**, чтобы снять выделение.

Для экспорта всей сессии нажмите вместо этого **Export WAV** (выделение не
требуется).

## 8. Редактирование клипов (Epic 4)

Клипы рисуются на дорожках прямоугольниками. Клик по клипу выделяет его
(оранжевая рамка) и включает действия в строке редактирования под транспортом.
Все кнопки этой строки — **только иконки** (как в строке действий и на
транспорте): наведите курсор, чтобы прочитать подсказку с названием действия и
горячей клавишей.

- **Перемещение:** тяните тело выделенного клипа влево/вправо.
- **Трим:** тяните левый или правый край клипа (примерно 1/4 ширины клипа).
- **Фейд:** тяните верхний левый / верхний правый угол клипа по горизонтали.
- **Привязка:** при перемещении и триме край «прилипает» к границам соседних
  клипов, к бегунку и к секундной сетке, когда он ближе ~6 px; жёлтая линия
  показывает границу, к которой произойдёт привязка. **Удерживайте `Alt`** во
  время перетаскивания, чтобы отключить привязку.
- **Удалить клип или дорожку:** **Delete** (иконка-корзина, `Delete`) удаляет
  только выделенный клип. Той же иконкой-корзиной помечена **Remove track** —
  она удаляет всю дорожку вместе со всеми её клипами: если выделен клип —
  удаляется его дорожка, иначе — последняя дорожка (так удаляется
  импортированный минус). Различить их помогают подсказки.

## Где что лежит

| Что | Расположение |
| --- | --- |
| Сессии (`.tracktionedit`) | `<app data>/raw-radio-studio/Projects/` |
| Записанные дубли | `Recordings/` рядом с файлом сессии |
| Временная версия автосохранения | `.tmp_<session name>` рядом с файлом сессии |
| Пресеты плагинов | `<app data>/raw-radio-studio/Presets/<plugin-key>/<name>.rrspreset` |

`<app data>` — это macOS `~/Library/Application Support`, Linux `~/.config`.
